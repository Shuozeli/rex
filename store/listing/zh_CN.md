## Description

rex 把你正在阅读的网页变成一条结构化的 JSON 记录，一键完成，全部在浏览器里进行。

在文章、列表、商品、视频或股票行情页面上点击 rex 图标，rex 会用该网站的配方，或网页公开的 schema.org 数据读取页面，并显示记录：文章的标题、作者、日期和正文；列表的条目；商品的价格；视频的频道和时长；行情的价格和各项数据。

• 阅读和数据表两种视图，底部是完整的 JSON。
• 复制 JSON 或下载 .json 文件：可以是带每个值来源的完整结果，也可以只是记录本身。
• 内置 1000 多个配方，覆盖常用网站和数百个新闻网站。其他发布了 schema.org 数据的网页（文章、商品、菜谱等）通过通用配方也能使用。
• 不联网。配方内置在扩展里。rex 从不连接互联网，不向任何地方发送数据，也不申请任何网站的访问权限：只在你点击图标时读取当前标签页。
• 中文和英文界面。
• 面向配方作者的开发者模式：显示每个字段是怎么找到的，可以运行你粘贴的配方，还能把网页保存为文字已替换的测试样例。
